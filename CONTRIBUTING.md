# Contribuir

Gracias por ayudar a mejorar NativeHDRShot.

## Preparar el entorno

1. Instala Visual Studio 2022 con **Desarrollo para el escritorio con C++**.
2. Instala el Windows 11 SDK.
3. Clona el repositorio.
4. Ejecuta `build.ps1` o abre `NativeHDRShot.sln`.

## Antes de enviar cambios

- Compila `Release | x64` sin avisos.
- Prueba una captura de región y una de monitor completo.
- Si modificas la conversión de color, prueba con HDR activado y desactivado.
- No incluyas `obj`, PDB ni capturas personales.
- Actualiza README, arquitectura o changelog cuando corresponda.

Describe en la pull request qué cambia, por qué y cómo se verificó.
